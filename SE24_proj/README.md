# 자동차 시뮬레이터 테스트 시스템

이 프로젝트는 자동차의 다양한 상태와 동작을 제어하고 검증하기 위한 자동차 시뮬레이터입니다. `unittest`를 활용하여 주요 기능을 자동으로 테스트하며, 각 테스트의 독립성을 유지합니다.

## 주요 기능

1. **시동**
   - `ENGINE_BTN` 명령을 통해 차량의 시동을 켜고 끌 수 있습니다.
   - 테스트 결과, 시동 상태가 올바르게 변경됨을 확인했습니다.

2. **가속**
   - `ACCELERATE` 명령을 통해 속도를 증가시킬 수 있습니다.
   - 테스트 결과, 속도가 200km/h를 초과하지 않음을 확인했습니다.

3. **브레이크**
   - `BRAKE` 명령을 통해 차량을 감속할 수 있습니다.
   - 테스트 결과, 브레이크 작동 후 속도가 0으로 감소함을 확인했습니다.

4. **잠금 및 잠금 해제**
   - 차량의 잠금(`LOCK`)과 잠금 해제(`UNLOCK`) 기능이 정상적으로 작동합니다.

5. **문 제어**
   - 차량의 왼쪽 및 오른쪽 도어를 열고 닫는 명령이 올바르게 작동합니다.

6. **트렁크 제어**
   - 트렁크를 열고 닫는 명령이 올바르게 작동합니다.

7. **긴급 상황 (SOS)**
   - 긴급 상황에서 차량이 정지하고 모든 문이 잠금 해제되며, 트렁크가 닫히는지 확인했습니다.

## 실행 방법

1. **테스트 환경 준비**:
   - Python 3.12.4 이상 설치.
   - `car.py`, `car_controller.py`, `main.py`, `test_main.py` 파일 준비.

2. **테스트 실행**:
   ```bash
   python -m unittest test_main.py

3. **결과 확인**:
   - 모든 테스트가 통과되면 "OK" 메시지가 출력됩니다.
